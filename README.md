# Basic Sales Summary from SQLite Database

This project is part of my data analyst internship. The objective was to connect Python to a SQLite database, run SQL queries to get basic sales summaries, and visualize the results with a simple bar chart.

## ✅ Objective

- Connect to a SQLite database (`sales_data.db`)
- Run SQL queries inside Python
- Display total quantity sold and total revenue per product
- Print query results
- Visualize revenue using a bar chart with matplotlib

## 🛠️ Tools Used

- Python
- sqlite3 (built-in SQLite support in Python)
- pandas
- matplotlib
- Jupyter Notebook

## 📂 Files Included

- `sales_data.db` – SQLite database file
- `sales_summary.ipynb` – Jupyter Notebook with the complete code
- `sales_chart.png` – Saved revenue bar chart
- `README.md` – This explanation file

## 💻 How to Run

1. Clone this repository
2. Open `sales_summary.ipynb` in Jupyter Notebook
3. Run the notebook cells step-by-step

👉 First cell **creates the database and inserts sample data** (run this once).
👉 Second cell **queries total quantity and revenue per product**.
👉 Third cell **prints the results and plots a bar chart**.

The chart will be displayed and also saved as `sales_chart.png`.
